# 架构总览

本文只说明可复用的开发架构。具体接口、字段和业务实现以已确认需求、源码和测试为准。

## 请求链路

```text
Request -> Controller -> Service -> Repository -> Model -> Database
                         |
                         +-> CacheManager/CacheScope -> Redis
```

数据库只使用默认连接 `mysql`（`config/database.php`），连接参数来自 `.env` 的 `DB_*`；业务代码不直接读取环境变量，也不在请求参数中动态选择连接。

| 层 | 职责 | 数据库访问 |
| --- | --- | --- |
| Request | 参数校验、字段名称、中文错误消息 | 禁止 |
| Controller | 接收请求、调用 Service、返回统一响应 | 禁止 |
| Service | 业务规则、事务、跨实体流程编排 | 仅调用 Repository |
| Repository | 对应数据表的 CRUD、条件与关联查询 | 允许 |
| Model | 单表映射、字段类型、关联、作用域、访问器 | 提供查询定义 |

## 一表一 Model/Repository

每张正式业务表对应一个 Model 和一个 Repository。类名、文件名使用业务实体名，不携带物理表前缀。

| 数据表 | Model | Repository |
| --- | --- | --- |
| `km_admin_users` | `AdminUserModel` | `AdminUserRepository` |
| `km_admin_roles` | `AdminRoleModel` | `AdminRoleRepository` |
| `km_admin_permissions` | `AdminPermissionModel` | `AdminPermissionRepository` |
| `km_admin_personal_access_tokens` | `AdminPersonalAccessTokenModel` | `AdminPersonalAccessTokenRepository` |

物理表名只保留在 Model 的 `$table`、FormRequest 校验表名和必要的查询表达式中。

纯关联中间表由 Model 的 Eloquent 关系维护，不创建空壳 Model/Repository。关联表具备独立业务字段和独立 CRUD 时，才作为业务实体建立对应两层。

## 数据层职责

```php
class AdminUserModel extends Model
{
    protected $table = 'admin_users';

    public function roles(): BelongsToMany
    {
        return $this->belongsToMany(
            AdminRoleModel::class,
            'admin_user_roles',
            'user_id',
            'role_id',
        );
    }
}
```

```php
class AdminUserRepository
{
    public function __construct(
        private AdminUserModel $model,
    ) {}

    public function findById(int $id): ?AdminUserModel
    {
        return $this->model->newQuery()->find($id);
    }

    public function loadRoles(AdminUserModel $user): AdminUserModel
    {
        return $user->loadMissing('roles');
    }
}
```

Repository 只能注入对应 Model。禁止用 `AuthRepository`、`OrderFlowRepository` 等流程名聚合多个表；跨实体流程由 Service 注入多个 Repository 编排。

## 写操作

```php
class UserService
{
    public function __construct(
        private AdminUserRepository $userRepository,
    ) {}

    public function update(int $id, array $data): AdminUserModel
    {
        DB::beginTransaction();

        try {
            $user = $this->userRepository->findById($id);
            ResponseHelper::errorIf(! $user, '用户不存在');
            $user = $this->userRepository->update($user, $data);
            DB::commit();

            return $user;
        } catch (Throwable $e) {
            DB::rollBack();
            throw $e;
        }
    }
}
```

## 约束清单

- Controller 不直接查询 Model。
- Service 不直接使用 `Model::` 或 Query Builder。
- Repository 只注入与其同名的 Model。
- Model 显式声明真实 `$table`。
- 关联关系定义在 Model，关联查询由对应 Repository 调用。
- 所有 API 响应统一通过 `ResponseHelper` 返回。
