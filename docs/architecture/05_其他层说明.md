## 请求校验层（Request）

### 位置
```
app/Http/Requests/
├── UserRequest.php
├── ProductRequest.php
└── OrderRequest.php
```

每个资源 Controller 对应一个同实体 Request。例如 `ProductController` 只注入 `ProductRequest`，不再按创建、更新、搜索拆成多个 Request 文件。

### 作用

`FormRequest` 负责：
- 请求参数验证
- 授权检查
- 自定义错误消息
- 中文字段名称

### 动作分发约定

- Controller 的全部路由动作都注入同一个 Request。
- `rules()` 根据当前 Controller 方法分发到 `rulesFor{Action}()`。
- 无参数动作也必须提供对应规则方法并显式返回空数组。
- 未登记的动作抛 `LogicException`，禁止静默使用空规则。
- 不把动作规则方法直接命名为 `user()`、`route()`、`input()`，避免覆盖 Laravel Request 已有方法。
- Request 只负责 HTTP 输入契约，不写业务逻辑或数据库查询。

### 标准写法

```php
<?php

namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;
use Illuminate\Validation\Rule;
use LogicException;

class UserRequest extends FormRequest
{
    public function authorize(): bool
    {
        return true;
    }

    public function rules(): array
    {
        return match ($this->controllerAction()) {
            'index' => $this->rulesForIndex(),
            'search' => $this->rulesForSearch(),
            'show' => $this->rulesForShow(),
            'store' => $this->rulesForStore(),
            'update' => $this->rulesForUpdate(),
            'destroy' => $this->rulesForDestroy(),
            default => throw new LogicException('UserRequest 未配置当前 Controller 动作的校验规则'),
        };
    }

    public function messages(): array
    {
        return [
            'name.required' => '用户名不能为空',
            'email.required' => '邮箱不能为空',
            'email.email' => '邮箱格式不正确',
            'email.unique' => '该邮箱已被使用',
        ];
    }

    public function attributes(): array
    {
        return [
            'name' => '用户名',
            'email' => '邮箱',
        ];
    }

    private function rulesForIndex(): array
    {
        return [
            'per_page' => ['nullable', 'integer', 'min:1', 'max:100'],
        ];
    }

    private function rulesForShow(): array
    {
        return [];
    }

    private function rulesForSearch(): array
    {
        return [
            'keyword' => ['nullable', 'string', 'max:100'],
        ];
    }

    private function rulesForStore(): array
    {
        return [
            'name' => ['required', 'string', 'max:50'],
            'email' => ['required', 'email', Rule::unique('users', 'email')],
        ];
    }

    private function rulesForUpdate(): array
    {
        return [
            'name' => ['sometimes', 'string', 'max:50'],
            'email' => [
                'sometimes',
                'email',
                Rule::unique('users', 'email')->ignore($this->route('id')),
            ],
        ];
    }

    private function rulesForDestroy(): array
    {
        return [];
    }

    private function controllerAction(): string
    {
        return (string) $this->route()?->getActionMethod();
    }
}
```

### 🎨 常用验证规则

```php
'field' => 'required',              // 必填
'field' => 'nullable',              // 可为空
'field' => 'string',                // 字符串
'field' => 'integer',               // 整数
'field' => 'numeric',               // 数字
'field' => 'boolean',               // 布尔值
'field' => 'array',                 // 数组
'field' => 'email',                 // 邮箱
'field' => 'url',                   // URL
'field' => 'date',                  // 日期
'field' => 'min:3',                 // 最小值/长度
'field' => 'max:100',               // 最大值/长度
'field' => 'between:1,10',          // 范围

'field' => 'regex:/^[A-Z]/',        // 正则
```

## 枚举层（Enum）

### 📍 位置
```
app/Enums/
├── OrderStatus.php
├── UserRole.php
├── PaymentStatus.php
└── PaymentMethod.php
```

### 🎯 作用

枚举（Enum）负责：
- 定义固定的常量集合
- 避免魔法字符串
- 类型安全
- 提供标签和业务方法

### 📝 标准写法

```php
<?php

namespace App\Enums;

enum OrderStatus: string
{
    case PENDING = 'pending';
    case PAID = 'paid';
    case PROCESSING = 'processing';
    case SHIPPED = 'shipped';
    case DELIVERED = 'delivered';
    case CANCELLED = 'cancelled';
    case REFUNDED = 'refunded';
    
    /**
     * 获取中文标签
     */
    public function label(): string
    {
        return match($this) {
            self::PENDING => '待支付',
            self::PAID => '已支付',
            self::PROCESSING => '处理中',
            self::SHIPPED => '已发货',
            self::DELIVERED => '已送达',
            self::CANCELLED => '已取消',
            self::REFUNDED => '已退款',
        };
    }
    
    /**
     * 获取颜色（供 API 客户端展示）
     */
    public function color(): string
    {
        return match($this) {
            self::PENDING => 'warning',
            self::PAID => 'info',
            self::PROCESSING => 'primary',
            self::SHIPPED => 'success',
            self::DELIVERED => 'success',
            self::CANCELLED => 'danger',
            self::REFUNDED => 'secondary',
        };
    }
    
    /**
     * 是否可以取消
     */
    public function isCancellable(): bool
    {
        return in_array($this, [self::PENDING, self::PAID]);
    }
    
    /**
     * 是否可以退款
     */
    public function isRefundable(): bool
    {
        return in_array($this, [self::PAID, self::PROCESSING, self::SHIPPED]);
    }
    
    /**
     * 获取所有枚举值
     */
    public static function values(): array
    {
        return array_column(self::cases(), 'value');
    }
    
    /**
     * 获取所有标签
     */
    public static function labels(): array
    {
        $labels = [];
        foreach (self::cases() as $case) {
            $labels[$case->value] = $case->label();
        }
        return $labels;
    }
}
```

### 📝 在模型（Model）中使用

```php

{
    protected $casts = [
        'status' => OrderStatus::class,

    // 可以取消

```

```
├── Handler.php
├── OrderNotFoundException.php

└── PaymentFailedException.php
```

### 🎯 作用

自定义异常负责：
- 业务异常定义
- 统一错误响应
- 错误日志记录

### 📝 自定义异常

```php
<?php

namespace App\Exceptions;

use Exception;

class OrderNotFoundException extends Exception
{
    protected $message = '订单不存在';
    protected $code = 404;
    
    public function render($request)
    {
        return response()->json([
            'success' => false,
            'message' => $this->message,
            'code' => $this->code,
        ], 404);
    }
}
```

### 📝 带参数的异常

```php
<?php

namespace App\Exceptions;

use Exception;

class InsufficientStockException extends Exception
{
    public function __construct(
        private string $productName,
        private int $requested,
        private int $available
    ) {
        parent::__construct(
            "商品 {$productName} 库存不足，需要 {$requested}，可用 {$available}"
        );
    }
    
    public function render($request)
    {
        return response()->json([
            'success' => false,
            'message' => $this->getMessage(),
            'code' => 400,
            'data' => [
                'product_name' => $this->productName,
                'requested' => $this->requested,
                'available' => $this->available,
            ],
        ], 400);
    }
}

// 使用
throw new InsufficientStockException('iPhone 15', 5, 2);
```

### 📝 全局异常处理

```php
<?php

namespace App\Exceptions;

use Illuminate\Foundation\Exceptions\Handler as ExceptionHandler;
use Illuminate\Database\Eloquent\ModelNotFoundException;
use Illuminate\Validation\ValidationException;
use Symfony\Component\HttpKernel\Exception\NotFoundHttpException;
use Throwable;

class Handler extends ExceptionHandler
{
    /**
     * 不需要报告的异常
     */
    protected $dontReport = [
        OrderNotFoundException::class,
    ];
    
    /**
     * 注册异常处理
     */
    public function register(): void
    {
        $this->reportable(function (Throwable $e) {
            //
        });
        
        // API 响应统一格式
        $this->renderable(function (Throwable $e, $request) {
            if ($request->is('api/*')) {
                return $this->handleApiException($e);
            }
        });
    }
    
    /**
     * 处理 API 异常
     */
    private function handleApiException(Throwable $e)
    {
        // 验证异常
        if ($e instanceof ValidationException) {
            return response()->json([
                'success' => false,
                'message' => '验证失败',
                'errors' => $e->errors(),
            ], 422);
        }
        
        // 模型未找到
        if ($e instanceof ModelNotFoundException) {
            return response()->json([
                'success' => false,
                'message' => '资源不存在',
            ], 404);
        }
        
        // 404
        if ($e instanceof NotFoundHttpException) {
            return response()->json([
                'success' => false,
                'message' => '接口不存在',
            ], 404);
        }
        
        // 其他异常
        return response()->json([
            'success' => false,
            'message' => app()->environment('production') 
                ? '服务器错误' 
                : $e->getMessage(),
        ], 500);
    }
}
```

## 中间件层（Middleware）

### 📍 位置
```
app/Http/Middleware/
├── CheckUserRole.php
├── LogApiRequest.php
└── ValidateApiVersion.php
```

### 🎯 作用

中间件负责：
- 请求预处理
- 权限检查
- 日志记录
- 响应后处理

### 📝 标准写法

```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class CheckUserRole
{
    /**
     * 处理请求
     */
    public function handle(Request $request, Closure $next, string $role)
    {
        if (!auth()->check()) {
            return response()->json(['message' => '未登录'], 401);
        }
        
        if (!auth()->user()->hasRole($role)) {
            return response()->json(['message' => '权限不足'], 403);
        }
        
        return $next($request);
    }
}

// routes/api.php
Route::middleware(['auth', 'role:admin'])->group(function () {
    Route::get('/api/admin/accounts', [AdminController::class, 'accounts']);
});
```

### 📝 记录日志的中间件

```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Log;

class LogApiRequest
{
    public function handle(Request $request, Closure $next)
    {
        $startTime = microtime(true);
        
        // 请求前记录
        Log::info('API Request', [
            'method' => $request->method(),
            'url' => $request->fullUrl(),
            'ip' => $request->ip(),
            'user_id' => auth()->id(),
        ]);
        
        $response = $next($request);
        
        // 响应后记录
        $duration = round((microtime(true) - $startTime) * 1000, 2);
        
        Log::info('API Response', [
            'status' => $response->status(),
            'duration' => "{$duration}ms",
        ]);
        
        return $response;
    }
}
```

## 📚 总结

### 各层职责一览

| 层次 | 职责 | 何时使用 |
|------|------|----------|
| **请求（Request）** | 请求验证、按动作分发 | 每个 API 资源对应一个 Request |
| **枚举（Enum）** | 常量定义 | 固定的状态、类型等 |
| **异常（Exception）** | 异常处理 | 业务异常 |
| **中间件（Middleware）** | 请求拦截 | 权限、日志、限流等 |

### 最佳实践

1. **请求（Request）**：将所有验证逻辑放在 `FormRequest` 中
2. **响应助手（ResponseHelper）**：使用统一的 `code/message/data` 结构返回 API 响应
3. **枚举（Enum）**：使用枚举替代魔法字符串和常量类
4. **异常（Exception）**：业务异常继承自 `Exception`，并提供清晰的错误信息
5. **中间件（Middleware）**：保持职责单一，并支持组合使用
